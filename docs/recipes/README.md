# Recipes

Short, copyable ways to use curtilage's results with other tools. Every example uses made-up coordinates near `[-80.0, 35.0]`; nothing here is a real site. Results are OpenStreetMap-derived: show the `attribution` they carry wherever you show them ([Data licence](../../README.md#data-licence)).

- [PostGIS](postgis.md): load results, query them, check points against them.
- [Geofences on your own server](geofence-server.md): point-in-polygon checks in Ruby or SQL.
- [Circles for mobile geofences](mobile-circles.md): Android and iOS take circles only.
- [Geofence platforms](geofence-platforms.md): polygons for services that accept GeoJSON.
- [QGIS](qgis.md): open a GeoPackage, style by flag.
- [DuckDB and GeoParquet](duckdb.md): analytics in SQL.
- [GeoPandas](geopandas.md): results in a GeoDataFrame.
- [Rails](rails.md): a background job that generates and stores premises.
